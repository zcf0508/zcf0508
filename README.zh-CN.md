## 开源项目

- [vue-scan](https://github.com/zcf0508/vue-scan) - 可视化 Vue 组件更新，帮助定位性能问题。
- [vue-hook-optimizer](https://github.com/zcf0508/vue-hook-optimizer) - 通过 AST 依赖图分析 Vue 和 React 组件，并提供 AI 辅助重构建议。
- [unplugin-devpilot](https://github.com/zcf0508/unplugin-devpilot) - 通过 WebSocket RPC 与 MCP 连接浏览器和 AI Agent。
- [autocut-client](https://github.com/zcf0508/autocut-client) - 基于 Electron 和 Vue 构建的 AutoCut 桌面客户端。
- [unplugin-https-reverse-proxy](https://github.com/zcf0508/unplugin-https-reverse-proxy) - 为 Vite、Webpack、Vue CLI 等构建工具提供本地 HTTPS 反向代理。
- [mem-mcp](https://github.com/zcf0508/mem-mcp) - 支持增删改查和自动淘汰机制的记忆 MCP Server。
